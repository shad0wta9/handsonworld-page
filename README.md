# HandsOnWorld

Project page for **HandsOnWorld: Unconstrained Egocentric Video Generation with Camera-Disentangled Hand Control**.

The website presents our method overview, interaction showcases, EgoVid-Pro annotations, and qualitative comparisons. It is deployed with GitHub Pages from the repository root.

## Local preview

Run a static HTTP server from this directory:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
